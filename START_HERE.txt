⚡ QUICK START (15 MINUTES)
================================================================================

1. INSTALL PREREQUISITES (5 minutes)
   • Node.js 18+: https://nodejs.org
   • PostgreSQL: https://postgresql.org/download/windows
   • Run: npm install -g pnpm

2. EXTRACT & INSTALL (3 minutes)
   • Extract project
   • Open PowerShell in project folder
   • Run: pnpm install

3. SETUP DATABASE (2 minutes)
   • Create database in PostgreSQL
   • Create .env.local with database URL
   • Run: pnpm seed

4. START APPLICATION (2 minutes)
   • Run: pnpm dev
   • Open: http://localhost:3000
   • Login: admin@wakili.local / Admin123!

================================================================================
🆘 HELP & TROUBLESHOOTING
================================================================================

Can't login?
  → Check email is: admin@wakili.local (exactly)
  → Run: pnpm seed (creates admin user)
  → Clear browser cookies

Port 3000 in use?
  → Run: pnpm dev -- -p 3001

Database connection error?
  → Check PostgreSQL is running
  → Verify DATABASE_URL in .env.local
  → Check password is correct

Module not found?
  → Run: pnpm install
